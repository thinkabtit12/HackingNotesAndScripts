nmap -p- --min-rate 2000 -v <TARGET_IP>

nmap port information command:
nmap -sC -sV -p (port1),(port2 and so on) <TARGET_IP>

web server redirect finder command:
curl -I http://<TARGET_IP>

link DNS to IP command:
sudo nano /etc/hosts
(scroll to the very bottom of the file, paste your target IP, press Tab, and then paste the DNS you link it to.)

nmap -p 143,993 <TARGET_IP>
(port 143 is standard imap, port 993 is secure imap)

smbclient connect command:
smbclient //<TARGET_IP>/backups -N

check shared folders over SMB anonymously (without password) command:
smbclient -L //<TARGET_IP>/ -N
(use this first to see the list of folders. ignore shares ending in $ as they are admin locked. target the custom ones.)

smbclient share downloader commands:
(once inside the smb shell with the smb: \> prompt, use these 3 commands)
ls
(lists everything in the shared folder to find configuration files or credentials)
get <FILENAME>
(downloads the targeted file straight to your machine so you can read it locally)
exit
(closes the connection to bring you back to your regular Linux terminal)

search for full path of any binary command:
which <TOOL_NAME>
(use this to find the exact location of a tool on a system, like finding /usr/bin/xxd)

find target configuration files based on file extension command:
find / -type f -name "*.conf" 2>/dev/null
(searches the entire machine for configuration files while automatically hiding permission denied errors)

count number of specific files on system command:
find / -type f -name "*.bak" 2>/dev/null | wc -l
(counts how many backup files exist on the target machine without cluttering the screen)
