STEP 1: FORCED LIVE SCANS VIA THIRD-PARTY INFRASTRUCTURE
------------------------------------------------------------------------
1. Go to Hackertarget.com -> Select "Nmap Online" -> Enter Target IP.
   - Run the live test. 
   - Footprint: Logged as Hackertarget infrastructure.

2. Go to Pentest-Tools.com -> Choose "Find Open Ports" (Free Light Scan).
   - Run the live test.
   - Footprint: Logged as Pentest-Tools infrastructure.

3. Log into Shodan.io -> Submit a "Refresh/Rescan" request for the IP.
   - Forces an immediate live update of the port profile.

STEP 2: CERTIFICATE TRANSPARENCY & SUBDOMAIN RECON
------------------------------------------------------------------------
1. Go to crt.sh -> Search the IP or suspected parent domains.
   - Extract: Subject Alternative Names (SANs) and hidden subdomains.
2. Go to SecurityTrails.com (Free Account) -> Run historical DNS check.
   - Extract: Past DNS records pointing to this exact IP.

STEP 3: ADVANCED ROUTING & BGP RECON
------------------------------------------------------------------------
1. Go to bgp.he.net -> Enter Target IP.
   - Extract: ASN Number, IP Prefix blocks, and upstream peers.
